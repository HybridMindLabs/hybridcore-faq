The official **FAQ** extension for [HybridCore](https://github.com/HybridMindLabs/HybridCore) — admin-managed, categorized frequently-asked-questions.

- 📚 Categorized question/answer entries, admin-ordered.
- 📝 Markdown answers, rendered server-side.
- 🔍 Client-side search across question + answer text.
- 👍 "Was this helpful?" feedback per entry, visible only to admins.

## Requirements

- HybridCore ≥ 0.3.0
